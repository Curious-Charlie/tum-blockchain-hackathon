# Vendored contract

`payment-v2.plutus.json` is Masumi's escrow validator (`vested_pay`, payment V2), unmodified, from `masumi-network/masumi-payment-service` `smart-contracts/payment-v2/plutus.json` at commit `69297f308f603bffbdfd4efccb54398eaff1bd87` (compiled with Aiken v1.1.23), via the x402-cardano-demo reference. `test/escrow.test.ts` checks that it hashes to the escrow address `@x402/cardano` expects.
